[h1]Hybrid Bees Mechanics[/h1]

This guide explains how bee crossbreeding works in the Genetic Hybridizer.

[h2]1. What goes into the Hybridizer[/h2]

[list]
[*]A queen bee from one species
[*]A drone from another species
[*]Optionally, a Research Microdisc, Holodisc, or Megadisc
[/list]

A successful attempt produces a [b]hybrid queen larva[/b], not an adult queen.

Both parent bees are consumed on every attempt. A valid research disc is also consumed, whether the attempt succeeds or fails.

[h2]2. Success chance[/h2]

Without a disc:

[list]
[*]Ordinary species: [b]30%[/b]
[*]Rival species: [b]10%[/b]
[/list]

Research disc bonuses:

[table]
[tr][th]Disc[/th][th]Normal bonus[/th][th]Rival bonus[/th][/tr]
[tr][td]Research Microdisc[/td][td]+15 percentage points[/td][td]+7.5 points[/td][/tr]
[tr][td]Research Holodisc[/td][td]+25 percentage points[/td][td]+12.5 points[/td][/tr]
[tr][td]Research Megadisc[/td][td]+30 percentage points[/td][td]+15 points[/td][/tr]
[/table]

The final chance cannot exceed 100%.

Examples:

[list]
[*]Ordinary species + Microdisc: [b]45%[/b]
[*]Ordinary species + Holodisc: [b]55%[/b]
[*]Ordinary species + Megadisc: [b]60%[/b]
[*]Rival species + Microdisc: [b]17.5%[/b]
[*]Rival species + Holodisc: [b]22.5%[/b]
[*]Rival species + Megadisc: [b]25%[/b]
[/list]

[h2]3. How traits are inherited[/h2]

Each trait is calculated separately from the queen's and drone's genes.

General rule:

[list=1]
[*]The Hybridizer reads the trait value from both parents.
[*]The lower parental value is used as the base.
[*]One third is removed, keeping approximately two thirds of the value.
[*]The result is rounded to the nearest genetic unit.
[*]If the original value was above zero, the result cannot be lower than 1.
[*]If both values were zero, the result remains zero.
[/list]

The hybrid does not automatically receive the average of both values. It receives a reduced version of the weaker parental trait.

[b]Example: values 3 and 1[/b]

[list]
[*]Lower value: 1
[*]Two thirds of 1: 0.67
[*]Positive minimum after rounding: 1
[*]Final result: 1
[/list]

[b]Example: values 6 and 3[/b]

[list]
[*]Lower value: 3
[*]Two thirds of 3: 2
[*]Final result: 2
[/list]

[h2]4. Traits with special rules[/h2]

[b]Subspecies[/b]

The larva randomly receives one of the two available hybrid subspecies. Both subspecies have the same appearance, but each prioritizes resources associated with a different parent.

The visible subspecies field shows:

[code]Predominant: [subspecies][/code]

This tells the player which production lineage was prioritized.

[b]Work time[/b]

Work time uses its own rule to preserve valid combinations and avoid incompatible extreme results.

[b]Mutation chance[/b]

Mutation chance starts from the higher parental value and receives a one-unit genetic increase, within the gene's internal limit.

[h2]5. Biomes and intolerances[/h2]

The hybrid retains the intolerances or dislikes from both parents. When both parents have an explicit value for the same biome, the result is the midpoint between those values.

[list]
[*]Both parents' intolerances are preserved.
[*]Conflicting values for the same biome are combined at the midpoint.
[*]A positive value still represents a favorable condition.
[*]A negative or extreme value still represents intolerance or danger, according to the Frackin Universe scale.
[/list]

Biome inheritance is independent of the subspecies choice.

[h2]6. Preferred plants[/h2]

The hybrid receives one preferred plant from each parent.

When preferences conflict, likeness is combined at the midpoint. The hybrid does not receive an unlimited preference list: one preference is selected from each side of the cross.

[h2]7. Rivalries[/h2]

A hybrid species is considered rival when the parent combination involves rival species.

[list]
[*]The hybrid retains rivalry derived from its parents.
[*]Rival species have a lower hybridization chance.
[*]A rival hybrid can become one of the rival participants in future crosses.
[/list]

[h2]8. Production in apiaries[/h2]

The resource and quantity table belongs to the Frackin Universe apiary. The bee provides identity, subspecies, and genetics for the apiary to use in its calculations.

[list]
[*]The apiary defines base resources, speed, slots, and processing rules.
[*]The bee provides the genetic data and lineage consulted by the apiary.
[*]The predominant subspecies determines which hybrid production line is prioritized.
[*]The hybrid can produce resources associated with both parent species, with reductions according to inheritance and production rules.
[/list]

[h2]9. Appearance[/h2]

Each hybrid species has its own sprite. Its appearance combines colors, patterns, and visual traits from both parents.

The two subspecies of the same hybrid species share the same appearance. Their difference lies in genetics, predominant subspecies, and production priority.

[h2]10. Progress and specimen changes[/h2]

The Hybridizer accumulates progress only when it has:

[list]
[*]A valid queen
[*]A valid drone from a different species
[*]An empty larva output slot
[*]Available power
[/list]

If an input is removed, the experiment pauses. Reinserting the exact same bee lets the experiment continue.

If one specimen is replaced:

[list]
[*]Existing progress is reduced by 50%.
[*]The machine shows a rework warning.
[*]The experiment continues with the new pair.
[/list]

[h2]11. Attempt result[/h2]

When progress reaches 10,000 points:

[list]
[*]Success: a hybrid queen larva is created.
[*]Failure: both parents are consumed and no larva is created.
[*]If a disc was inserted, it is consumed with the attempt.
[*]After the result, the progress cycle resets.
[/list]

This guide deliberately excludes the miteResistance gene.

[h2]12. Planned hybrid production rule[/h2]

The production model combines both parent production profiles, using the predominant parent as the larger share.

Example:

Parent A produces:

[list]
[*]5 of resource E
[*]2 of resource F
[*]6 of resource G
[*]1 of resource H
[/list]

Parent B produces:

[list]
[*]3 of resource X
[*]6 of resource Y
[*]10 of resource Z
[/list]

If the hybrid has the same production capacity and Parent A is predominant, the calculation uses:

[list]
[*]Two thirds of Parent A's production
[*]One third of Parent B's production
[/list]

The hybrid receives the combined resource profile of both parents. A resource produced only by Parent A uses the 2/3 share. A resource produced only by Parent B uses the 1/3 share. If both parents produce the same resource, their quantities are combined using these same weights.

This is a planned correction to the production system. Final integer rounding and exact apiary integration still need to be implemented and verified.


[h2]13. Hybridizer status outputs[/h2]

The Genetic Hybridizer exposes four binary output nodes for automation:

[table]
[tr][th]Node[/th][th]Signal condition[/th][/tr]
[tr][td]0[/td][td]A valid experiment is actively accumulating progress[/td][/tr]
[tr][td]1[/td][td]A supported research disc is present[/td][/tr]
[tr][td]2[/td][td]The larva output slot is occupied[/td][/tr]
[tr][td]3[/td][td]Valid parents are present, the output is free, and the machine can accept progress[/td][/tr]
[/table]

Signals are updated only when their state changes. The power input remains separate from these status outputs.
